## 3. 唯一权威与来源落实

在同一 Repository／AuthorityService 增加 `MaterializeGeneratedSource`，只接受 Owner、Scope、活跃 Run 和已接纳角色，不接收 UI 提供的物品定义或数量。从原计划取得稳定容器／物品 ID 与真实数量，首次整体放入 8×8 来源世界格；空间不足拒绝整次操作，不截断计划。重复请求先重放原回执，不补回已拿走的内容。

保留原来源计划作为不可变生成历史。实际剩余位置和数量只在原 Item／Container／Grid 图中；来源预览不是可写库存。载入核对来源落实回执、确定请求身份、内容、Owner／Scope、Run 时序、世界格及基础来源物身份／定义／元数据。不新增来源账户或物品数量后端。原计划中的生成分值仍不进钱包。

Service 复用同锁、原子替换、比较交换与重读证明，Subsystem 是 Ready／GameThread／Owner 检查的薄端口，保存后同步恢复状态。替换前失败精确回滚；替换后若重开证明精确后态，可按既有 ResolvedAfterReopen 确认。无法证明时不显示成功、不换请求身份、不退回 Code A／Code B。

## 4. 活跃局内格子与携带余额

新增显式 `EditActiveRunGrid`，复用原 Move／Split／Merge 几何、版本、部分堆叠、数量、回执与持久语义。仅允许当前 Owner／Scope 的普通背包、安全格和本 Run 来源世界格；禁止远程仓库、旧 Run 世界容器及局内装备更换。原 `EditGrid` 整备端口仍在活跃 Run 中锁定。

原出发数量物在既有消耗账本中，不能直接令 UI 再造一份 Stored 数量。本轮只读投影按原预留、已确认普通消耗和治疗终结回执算剩余，占用原返还格，阻止新物偷占该位置。拖动预览从真实权威快照建立临时验证副本，提交只发命令，显示投影不送载入或保存端口。存在未终结数量／资源意图时投影和新编辑失败关闭，不隐藏未确认消耗。

原携带物暂只读，新获得物与安全格可以整理。这是明确的过渡限制，不是完整 Goal 背包整理已完成。不同来源记录的同类物仍沿用旧元数据等值合并规则，会说明“来源记录不同”并原样保留；跨来源可合并的来源账本归并仍待开发。

## 5. 搜索和 UI 接线

首次约一秒搜索完成后，先确认原计划，再确认实际来源图，成功才打开既有 InventoryWidget。左侧来源格替代局外仓库，中间普通背包，右侧安全格和装备。标题按真实来源 Slots 显示可领取或已搜空；重新打开已搜索来源立即重放，不增量造物。Tab 可打开普通局内背包，局外仓库不在其中开放。

新物支持拖放、旋转、拆分一半、便捷转移和部分堆叠，确认后刷新实际图及 HUD 药数；失败保留原态或明确进入恢复。格子满、非法安全格、原携带只读及来源元数据不兼容均有中文提示。技术身份只入日志，不塞玩家主界面。开背包停止移动／攻击／格挡与撤离，世界和敌人继续；失焦清表面并暂停，死亡关闭背包再终局。

代码没有新增 Tick 物品快照拷贝；显示刷新与拖动指针变化仍使用已有快照复制方式。历史回执、来源和 tombstone 累积，真实帧耗时、内存与多局对象释放尚需实测，不能用世界记录字节数或代码复用 Actor 当作性能证据。

## 6. 带回和死亡规则

在既有 `FinalizePreparedRun` 内闭合活跃格子，仍一次持久提交。撤离保留已确认领取到普通背包／安全格的 Stored 物，按原账本返还原携带余额；未领取的本 Run 世界物销毁，不被当作奖励。原返还位置受到投影碰撞保护。

死亡／放弃销毁当前普通背包的新物和本 Run 未领取世界物，原普通装备与数量物沿用既有损失。死亡前已确认仍在安全格中的物保留；移出到普通背包者不再保留。局外仓库、钱包、安全格装备不变。此组合只在使用过新 Run 格子命令的局内生效，未接新格子的历史终局路径不被重新解释。

回执绑定 Run 并校验时序，终局及领取重放不重复返还。来源容器留空作为稳定历史，不删除档或回执来“修复”。下一局使用既有基础补给与正常出发路径。

## 7. 新药与兼容

治疗增加 StoredCarry 来源读取，取同一物品图的真实普通背包药数；不是从生成计划或世界容器远程吃药。HUD 普通数量包括原携带余额和已领取普通药，安全格单独统计。新药复用既有世界意图、正式 Reserve／Commit、确认后加最多 35 生命的治疗事务，不改伤害、动作或冷却参数。最后一颗清除格子后，恢复只能用精确已提交预留匹配 tombstone，不能另选替代药。

物品 Schema 6 不增字段，操作 enum 只尾部追加；旧数值和整备命令 fingerprint 保持。世界未用药时仍 333 字节，有待确认用药时仍 366 字节；Origin 增加值 2。新版可读旧 0／1 记录，不能声称旧 DLL 能理解新操作或 Origin 2，须退出旧进程再启动同一新版。来源内容、随机流、原计划和初始目录不重抽、不重置。
