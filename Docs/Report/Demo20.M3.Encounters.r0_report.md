## 3. 随机内容与来源边界

新内容 r2 为两个独立 50% 近战／50% 远程普通槽位加固定精英，普通组合有四种。每个区域初始位置选固定区域中心 X±220、Y±320 的四点之一；布局、门洞、宝匣候选和资源目录不变。两处普通守卫可能同类，不保证每局同时出现近战与远程；不同局出现相同结果合法。

每个区域有独立命名空间和流，输入包含 Run、原有 RunSeed、内容版本和区域。复用已有确定性随机器，不调用全局随机、帧时间或新 GUID；宝匣位置／掉落使用原通道，搜索顺序不能改变遭遇。历史六个来源角色和来源内容 stamp 不改，Enemy.Melee／Enemy.Ranged 仍是原槽位身份；玩家遗物标题改为石径／竹林／遗坛，不将 ID 名称误认成实际类型。精英槽位仍对应原精英掉落规则，未增奖励或第二份数量。

世界已有 ContentId 识别 r1／r2；Combat 的 EncounterRevision 是由该字段解码的内存值，不另加序列化字段。r1 的原内容 ID、种类、生命上限和固定位置保持。r2 重新派生类型规格，但使用存盘确认的位置、生命、revision、预警目标和计时，不回到随机初始点。

CaptureWorld 不再强行覆盖成当前内容。CAS 保存拒绝同一确认 Run 更换 ContentId，未知版本或内存 revision 与 ContentId 不一致失败关闭。旧可执行文件留下的已确认出发预检世界沿用其确切内容，新的 Session 从它恢复再提交携带启动；不会把新生成战斗与旧预检世界混合。缺失／损坏记录仍不回退旧备份复活敌人，玩家安全修复入口仍待后续。
