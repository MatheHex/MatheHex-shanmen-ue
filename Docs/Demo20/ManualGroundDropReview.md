# 山门 Demo2.0 地面丢弃与拾回人工审查

本说明检查普通背包与安全格主动丢弃、地面行囊、再次领取和终局。对应 [地面丢弃 Report](../Report/Demo20.M3.GroundDrop.r0_report.md)。代理本轮不接管窗口，实际画面、碰撞、输入和战斗中整理仍待人工；可以稍后反馈，不暂停独立开发。既有普通丹药正常反馈不扩大为本增量通过。

## 版本与隔离档

先正常退出旧游戏或 Editor，避免旧 DLL 驻留。不删除、搬移或编辑存档，不覆盖真实玩家档。项目目录按已编译 Report 基线运行：

```powershell
./Scripts/Start-Demo20.ps1 -Action Play -ProfileName ManualGroundDrop_20261005 -Width 1280 -Height 720 -TestMoney 1000000
```

1080p 检查时正常退出，以同一档名和 `-Width 1920 -Height 1080` 再启动；旧档不会重复初始化货币。使用正常整备、出发和搜索，不通过控制台发物。现有治疗和统一背包隔离档保留原样。

## 丢弃和同一物品拾回

出发后先到安全处，按背包键，默认 Tab。记录丹药数量与位置，选择普通背包中的丹药，点击“丢弃所选整堆”。这是整堆操作；若只想丢一部分，先点击“拆分一半”，再选择需要丢的那堆。丢弃确认前失败不应移走原物品；不要靠连点试探保存状态。

成功后普通背包数量减少，关闭背包，应在脚下看到低矮金色地面行囊。它没有碰撞，不应挡路。靠近按现有交互键，默认 G；地面行囊无需重新随机搜索，左侧显示实际剩余物。拖回普通背包或合法安全格，或选择物品点击“移入普通背包”。总数应恢复到丢弃前，而不是多出一份。已拾空行囊变灰，重新打开显示“已搜空”，不能重抽或补回。

背包满、占格冲突、非法安全格物品或边缘放置失败时，物品继续留在地面。部分合并只转移目标能容纳的数量，其余保留在地面原堆。当前跨来源同类仍不能合并，失败应保留两堆；这项限制未由本轮解除。

已穿戴武器、护具和储物装备不能从该按钮丢弃，也不能在局内更换。普通背包中的未穿戴武器可丢弃；旋转后丢出再拾回，检查方向和占格正确。不要把“拖回宝匣”误当作主动地面丢弃。

## 安全格与终局

将一份丹药或材料移入安全格并确认保存，再主动丢出。预期它立刻失去安全格保护；死亡或撤离前没有拾回，不会带回，也不会在安全格补出一份。保留另一份已确认安全格物作非零对照；死亡后仍在安全格的内容、护命匣、仓库与测试钱包保留。

另一次正常拾回并放入安全格，死亡应按当前已确认位置保留；拾回普通背包后死亡应损失。成功撤离只带回已拾回的合法携带内容，地面剩余物不算奖励。保存确认后再返回整备，检查没有旧账本重复返还。

## 重启、提示和输入

丢弃后正常关闭背包，Esc 暂停，保存返回入口并正常退出。重启同档继续原局，地面行囊应在原位置，数量与来源不变。拾回、部分合并或再次丢弃后重复检查；已经拾空的旧行囊不能重新补满，新一局不应看到上一局行囊。

720p 与 1080p 检查丢弃按钮、格子、数量、拒绝提示及返回操作。世界继续运行，打开背包停止玩家移动与攻击但不暂停敌人；实时战斗由人工检查。Esc、Tab、取消拖放、失焦及恢复后不得遗留移动、攻击或格挡。空地面行囊在宝匣附近不应让交互键无法打开宝匣。

若看到恢复中、未确认保存、物品数量异常、地面不可达或卡输入，保留隔离档与日志；记录档名、物品、前后数量、位置、操作及版本，方便时附图。不要删档、改存档或用调试补偿。相关问题路径暂不叠加开发，其余独立工作继续。无头测试不能代替此审查，也不能证明完整 Demo 已验收。
