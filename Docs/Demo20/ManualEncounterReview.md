# 山门 Demo2.0 随机遭遇人工审查

本增量仅接新局的敌人种类与初始位置变化，不增加敌人数量或声称达到完整探索时长。石径与竹林各自从近战／远程中选择，遗坛固定精英；两处普通守卫可能同为一种，连续两局也可能相同。代码和无头测试不是实际战斗通过证明。实时操作交人工，不阻塞其他独立开发。

## 隔离启动

先关闭旧版本游戏，不删除或修改真实存档。使用新 DLL、正常 UI，不用控制台发物、降血、造种子或改敌人。

```powershell
./Scripts/Start-Demo20.ps1 -Action Play -ProfileName ManualEncounter_20261005 -Width 1280 -Height 720 -TestMoney 1000000
```

另一分辨率为 1920×1080。继续原局使用同一档名。本文不授权自动操作窗口，也不恢复暂停的自动任务。

## 新局类型与实际行为

1. 正常整备后出发，沿路接近三个区域。石径／竹林提示的敌人类型应与实际颜色、移动和攻击相符：近战褐色靠近，远程紫色保持距离并预警玩家落点，精英红色较大、预警较长。
2. 同一区域不因打开背包、取消搜索、用药或暂停而换种、补满生命、移动回初始点。不要用打开背包当安全暂停，敌人继续行动。
3. 若危险，先撤回安全入口。测试基础攻击、闪避或格挡时可按已有操作说明；不要求持续高压战斗来强造样本。药品最多恢复 35 生命并只扣一颗，原普通药通过不顺带证明本组合。
4. 正常撤离／死亡、返回整备并再出发，观察新局可能变化；同一组合或位置重复是合法随机结果，不据此判失败。未见某种敌人记未覆盖，不用调试生成。

## 保存与旧局恢复

记录某敌人类型、位置、已受伤或死亡的状态。在安全处 Esc 保存并返回入口，再继续该局；或正常关闭后重开同一隔离档。已确认的移动位置、生命、死亡和预警不能被新候选替换。恢复时默认为暂停，按住输入不恢复；移动／计时原有最多约一秒确认粒度保持。

如已有此前固定三类守卫的隔离档，可以用新版正常继续，其旧局仍按固定旧版本，不要求升级随机组合。不要让旧 DLL 读取已经写入新内容的档。恢复失败时保留档与日志，不删档“修复”，不自行损坏文件制造失败。

## 来源与回传

守卫死亡后原位置出现对应区域遗物。近战／远程变化不增加第二份来源，不补回领取过的物品；搜索顺序不改变已确认的来源结果。没有某种同类掉落记未覆盖。来源整理、安全格、地面与混合药仍按各自人工步骤验收。

每项请注明档名、分辨率、区域、实际类型、重启前后状态、提示及截图／日志位置，分别标通过、失败或未覆盖。实际颜色／碰撞／行为／焦点、PIE／Standalone、性能和多局对象释放尚未由代理验证；发现失败的路径保留问题，不继续叠加，其他独立工作照常推进。
