## 最小普通丹药检查

1. 在“仓库与整备”确认普通背包有回春丹，记下数量；通过正常“出发”进入正式探索，不选石庭练习。
2. 让近战守卫造成一次非致死伤害，然后沿来路撤到入口方向、脱离攻击范围。不要在敌人身边站住等待代理或截图。
3. 松开鼠标右键，停止出剑或闪身，等待动作恢复。按一次数字 `1`，观察生命、普通药数和提示。可先按 Esc 暂停记下用药前状态，继续后用药，再 Esc 观察结果。
4. 预期一次最多恢复 35，生命上限 100，且普通药只少 1。例如安全条件下 60 → 95；80 → 100。普通与安全格药都存在时，先扣普通药，安全格不变。
5. 若期间又被攻击，净生命变化可能小于 35，不据此直接判定治疗失败；记录攻击与提示，在安全情况下重试一颗。不要为取得“好看”结果修改生命或药数。

Esc 是实际暂停；窗口失焦会暂停，恢复需要点击继续。当前局内背包／搜索尚未开放，不能将未来背包暂停规则当成当前测试入口。此检查不要求击败精英或全图战斗。

## 可选边界与安全格检查

在安全处继续检查：满生命按 `1` 应拒绝且不扣；按住右键格挡时应拒绝；两次很快轻按 `1`（恢复时间 0.6 秒内）只允许第一次合法治疗，第二次不额外扣药。动作恢复后再次合法用药则可以再扣 1。不要用长按结果替代具体的两次按键记录。

安全格检查在局外整备中将丹药正常转入已装备护命匣，确认普通背包没有丹药、安全格有药；再出发并重复非满生命检查。安全格一次少 1，普通仍为 0。安全格装备和已确认剩余药品按既有死亡规则保留，已消耗的一颗不返还。不要在活跃 Run 的整备锁上绕路转移物品。

治疗确认后，在 Esc 菜单正常保存原局并返回入口，再正常关闭、重启同档、继续原局，确认没有返还已用药品或再次应用同次治疗；生命、位置等恢复到最近确认状态，移动与计时允许既有约 1 秒粒度。不要把正常重启测试改为杀进程。保存失败的画面测试另行安排受控开发夹具，人工不改真实文件权限。

## 异常处理与反馈

出现“处理中／恢复中／保存失败”时，不把它当成功；不要强行开始新局、换药、删除档案或绕过提示。先暂停，保留日志与画面。若有重复扣药、免费治疗、丢物或持续输入，停止该检查步骤，留下当前档，其他开发继续。

反馈只需包含：档名、是否正式探索、用药前后生命和普通／安全格数量、按了什么键、屏幕提示、是否同时受击，以及是否做过重启。有截图时附前后两张即可；技术 ID 和种子不需要手工抄到玩家记录。

人工观察通过后仍要与对应版本和日志核对；不能由入口 Ready、原生自动化或旧死亡截图代替治疗通过。当前未完成的安全格、失败反馈、720p／1080p、PIE 及完整探索验收继续列在 [阶段状态](ExpeditionStatus.md)。
