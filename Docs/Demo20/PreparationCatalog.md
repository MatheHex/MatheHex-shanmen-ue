## 隔离新档配置

新档装备青锋剑、素纹道袍、基础行囊和护命匣，普通背包带 8 颗回春丹，安全格有 1 块碎玉佩。仓库提供玄铁剑、护身皮甲、扩容行囊、12 份灵草、6 块玄铁矿及 1 份残卷，用于真实整备操作。默认仓库 12×8。

测试钱包默认 1,000,000，允许启动配置 1 至 1,000,000,000；仅该档首次创建时生效。重新打开同一档只读取已确认结果，不补发物品、不改变初始配置、不给现存数量叠加货币。当前不要求也不提供商店。

## 容量替换和失败处理

装备替换把旧装备原子移到新装备原先所在的位置。若旧装备放不下，或更小背包装不下已有内容，整条命令拒绝。尺寸变化保留内容的二维坐标并重新计算锚点，不自动整理、不删除物品。未装备储物容器为空且禁用，不能借占位几何继续存物。

保存失败会回滚整个候选，包括装备、容量、位置、数量和回执；状态不确定时进入既有恢复路径，不显示“已保存”。成功命令记录请求身份，精确重试及重启重放不会再次执行。

## 未完成的产品能力

有限补给已采用 [固定缺失补给规则](BasicSupplyPolicy.md)，不重发完整新档。仓库替代装备算已拥有；每次正式死亡最多一次非空补给，缺药仅发 2 枚回春丹，货币不变。持久事务已实现，实际玩家死亡后的领取与再次出发仍待正式 Run 接线。

两种武器与护具尚未改变石庭练习的固定攻击和防御配置。丹药尚不能在练习中使用；安全格死亡保留目前只有放置策略，玩家死亡终局尚未接线。正式 Run 出发、随机敌人/宝箱/掉落、搜索、丢弃拾回和原局恢复继续属于当前完整目标，不从阶段范围中删除。
