# 山门 Demo2.0 跨来源堆叠人工审查

本轮允许不同宝匣、守卫和整备带入的普通同类物品合并，仍由一个物品权威保存。代码与无头回归不代替真实拖放；本说明供人工操作，开发不等待反馈才继续其他独立项目。旧普通丹药反馈只证明当时主路径，不证明混合堆的新组合。

## 启动与安全

关闭旧版本游戏后，从工程目录启动新的隔离档；不要删除、修改或复制真实玩家存档，不使用控制台降血或发物。

```powershell
./Scripts/Start-Demo20.ps1 -Action Play -ProfileName ManualStack_20261005 -Width 1280 -Height 720 -TestMoney 1000000
```

另一分辨率使用 `-Width 1920 -Height 1080`。重新打开同一档检查持久结果；每次不需要新建档。不要让旧 DLL 打开新版已经写入的记录。本轮不打包，不自动控制游戏窗口。

## 普通来源与部分合并

1. 经正常整备出发，记录携带药数量。探索和搜索宝匣／守卫遗物，寻找与携带物或另一来源相同的丹药、材料、战利品。
2. 搜索结果随机；没有同类掉落不是错误，不用调试发物强造样本。可以正常完成该局后再出发。若无法得到样本，记“未覆盖”，不要记通过。
3. 把同类来源堆拖到已有堆上。记录合并前后两堆数量、原位置和提示。两堆总量应相等，目标不超过目录上限；若只容纳一部分，余量仍在原来源或地面。
4. 目标已满时再次尝试，预期明确提示已达上限，位置、数量均不改变。重开面板和重复拖放不能补回已移出的物品。
5. 将新合并的普通堆拆开，放入合法安全格或普通背包；丢弃普通堆并拾回。界面、HUD 和来源余量应一致，没有复制或数量丢失。

背包和搜索面板打开时敌人继续行动，请先确认周围安全。收集证据时记录实际数量，不要只写“合并正常”。

## 治疗与终局

- 混合药堆受伤后在安全处使用一次：最多恢复 35 生命、只扣一颗；满生命应拒绝。松开格挡并等待动作恢复。不要求操作危险战斗来强行造样本。
- 成功撤离后确认普通／安全格实际带回数量，重开同一档仍一致，再正常出发。不能返还早已消耗或并入其他堆的旧携带余额。
- 另一次死亡时，普通位置的混合堆损失，已确认安全格的混合堆保留；仓库不受影响。原来源不决定死亡保护，实际确认的位置决定。
- 尚有原局时 Esc 保存返回入口，再继续原局，已领取来源、余量和混合数量不重抽、不补满。保存失败／恢复中的可见提示仍待真实环境验证，不手工损坏存档。

## 回传结果

每项注明分辨率、档名、操作前两堆数量、操作后数量、提示、是否重启，以及截图／日志所在位置。请分别报告“通过”“失败”“未覆盖”，并说明样本来自整备、宝匣、守卫或地面。本轮未做代理实际输入与新截图，不能据此宣布完整 M3 或 Demo 已验收。
