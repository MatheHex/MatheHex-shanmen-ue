# 山门 Demo2.0 随机来源搜索人工审查

本次审查只覆盖随机宝匣位置、守卫遗物、首次搜索及持久只读内容预览。领取、丢弃、拾回、局内网格和新拾取丹药尚未开放，不把“搜索已保存”当作“物品已进背包”。原有治疗不调参，普通丹药人工主路径已确认。

## 版本和隔离档

使用本轮 Sources Report 对应的已编译基线。先退出自己的旧游戏／Editor，再从项目目录启动；不要删旧档或使用控制台。推荐新审查档，测试货币只初始化一次：

```powershell
./Scripts/Start-Demo20.ps1 -Action Play -ProfileName ManualSources_20261005 -Width 1280 -Height 720 -TestMoney 1000000
```

默认交互键是 G，若有自定义绑定，以底部注册表提示为准。按 Tab 整备并携带后出发。地图仍是三只固定守卫，随机敌人组合和 10–15 分钟内容量待开发。

## 搜索和内容

每个区域有一只金色宝匣，从区域上／下两个候选位置选一个。沿路探索，不需要击败精英才能撤离。近战／远程／精英死亡后出现低矮金色遗物标记，可使用同一交互键。

靠近宝匣或遗物后按一次交互键。首次约 1 秒，玩家停止移动、出剑与格挡，但世界和敌人仍继续；受伤或位置改变会中断。不要站在敌人预警中等待搜索，先清理附近威胁或取消搜索避险。

完成后预览列出中文物品名称与数量，并明确显示“尚不能领取”。普通／安全格药数与仓库不应因为搜索增加。预览中没有领取按钮；本轮不验证容量取舍。

点击关闭或按 Esc 返回。再次打开同一来源应立即显示同一结果，不再次读条、不变更名称／数量。取消首次搜索不生成内容，也不增加背包数量；重新交互应重新计时。

## 恢复和输入

同一 Run 中记录宝匣位置和预览内容，按 Esc 暂停后保存返回入口或正常退出。重启同一隔离档、继续原局：宝匣位置相同，已经搜索的来源立即显示原内容，未搜索的来源仍需读条。开始新一局可以不同，但单个新局偶然相同不是错误。

搜索或预览中切换窗口，预期实际暂停并清理旧输入。返回后点击继续，不能遗留移动、攻击或格挡。搜索未确认完成时，失焦不应使它悄悄完成。

在 1280×720 和 1920×1080 分别检查搜索卡片、四行物品、关闭按钮和底部提示。较长内容不得遮住主要操作；源 ID、种子和技术诊断仅在日志里。

## 反馈和安全

可反馈“档名／哪个区域／首次是否约 1 秒／重复是否立即且相同／受伤和取消是否中断／重启是否保持／界面是否遮挡”，有方便的截图即可，不要求记录哈希。

若看到恢复中、保存未确认、数量异常或内容改变，保留档案和日志，不删档、不改权限、不通过调试发物补偿。暂停相应功能的叠加开发并核对原因，其他独立开发继续。环境不能可靠完成画面或输入检查时，保留为待人工确认，不宣称完整 Demo 或 M3 验收完成。
