为避免混淆，将基线中现存的物品管理实现统称为“代码 A”。代码 A 包括但不限于：

Fdemo_mapItemAuthority 及其 Item／GUID／Quantity／Equipment／Stash 写入路径；

demo_mapProfileSettlementTransaction、SettleRunItems 和既有终局物品提交路径；

demo_mapWorldItem、demo_mapItemSubsystem 及现有世界丢弃／拾取／空间 Bundle 路径；

与上述系统直接耦合的旧测试、调试命令和临时兼容逻辑。

代码 A 在本任务中可以继续维持基线可运行，不要求立即删除或禁用；但它只属于待替换的遗留实现，不再是 0.0.9B 新开发功能的设计权威。

代码 B 接管某一纵向流程后，该流程对应的代码 A 生产写入应从正式运行路径退出，不能保留两个可同时触发的入口。
